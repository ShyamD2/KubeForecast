WHAT IS THIS PROJECT? (THE 60-SECOND PLAIN-ENGLISH SUMMARY)
1. The Problem (Cloud Bill Waste)

When companies run applications on AWS Kubernetes, the standard scheduler scatters them randomly across all servers. Because each server ends up with just 1 or 2 small apps, AWS forces the company to pay for every single server 24/7—wasting millions on empty, unallocated hardware.

2. The KubeForecast Solution

KubeForecast acts like an intelligent airport gate manager. It predicts safe capacity, packs newly created apps tightly onto Target Node 1, and intentionally leaves Nodes 2 & 3 completely empty with zero active workloads.

3. The Real AWS Result (50-66% Saved)

Because Nodes 2 & 3 are left 100% empty, the AWS Autoscaler can safely power them off ($0/hr). This cuts the company's AWS cloud bill by 50% to 66% while keeping customer applications completely safe and fast!
